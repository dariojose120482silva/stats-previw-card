Frontend Mentor - Componente de cartão de visualização de estatísticas (Stats preview card component)
Boas-vindas! 👋
Obrigado por conferir este desafio de codificação front-end.

Os desafios do Frontend Mentor ajudam você a melhorar suas habilidades de programação ao construir projetos realistas.

Para fazer este desafio, você precisa de uma compreensão básica de HTML e CSS.

O desafio
Seu desafio é construir este componente de cartão e deixá-lo o mais próximo possível do design original.

Você pode usar qualquer ferramenta que desejar para ajudá-lo a concluir o desafio. Então, se você tem algo que gostaria de praticar, sinta-se à vontade para tentar.

Seus usuários devem ser capazes de:

Visualizar o layout ideal dependendo do tamanho da tela do dispositivo.

Quer ajuda com o desafio? Junte-se à nossa comunidade e tire suas dúvidas no canal #help.

Onde encontrar tudo
Sua tarefa é construir o projeto de acordo com os designs dentro da pasta /design. Você encontrará as versões mobile (celular) e desktop do design.

Os designs estão em formato estático JPG. Usar JPGs significa que você precisará usar seu bom senso para estilos como font-size (tamanho da fonte), padding (espaçamento interno) e margin (margem).

Se você desejar o arquivo de design do Figma para inspecionar o design em mais detalhes, você pode assinar como membro PRO.

Você encontrará todos os arquivos necessários (assets) na pasta /images. Os arquivos já estão otimizados.

Também há um arquivo style-guide.md contendo as informações que você precisará, como paleta de cores e fontes.

Construindo seu projeto
Sinta-se à vontade para usar qualquer fluxo de trabalho com o qual se sinta confortável. Abaixo está um processo sugerido, mas não sinta que precisa seguir estes passos:

Inicie seu projeto como um repositório público no GitHub. Criar um repositório facilitará o compartilhamento do seu código com a comunidade se precisar de ajuda.

Configure seu repositório para publicar seu código em um endereço web (URL). Isso será útil se precisar de ajuda, pois você poderá compartilhar a URL do projeto ao vivo junto com a URL do repositório.

Analise os designs para planejar como você abordará o projeto. Este passo é crucial para pensar antecipadamente em classes CSS e criar estilos reutilizáveis.

Estruture seu conteúdo com HTML antes de adicionar qualquer estilo. Escrever o HTML primeiro ajuda a focar na criação de um conteúdo bem estruturado.

Escreva os estilos base para o seu projeto, incluindo estilos gerais como font-family e font-size.

Comece a adicionar estilos do topo da página para baixo. Só avance para a próxima seção quando estiver satisfeito com a área em que está trabalhando.
